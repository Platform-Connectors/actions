# platform-connectors/actions

A collection of reusable GitHub Actions composite actions for Platform Connectors repositories.

## Available actions

| Action | Description |
|--------|-------------|
| [ci](./ci/README.md) | Run Python linting, type checks, tests, and coverage as a reusable composite action |
| [publish-library](./publish-library/README.md) | Publish a Python library to PyPI |
